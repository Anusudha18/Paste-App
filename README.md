# Paste App

A modern and responsive paste management application built with **React.js**, **Vite**, and **Tailwind CSS**. The application enables users to create, edit, organize, search, and manage text snippets efficiently through an intuitive user interface.

## 🚀 Live Demo

🔗 https://paste-app-anusu.vercel.app

---

## 📌 Overview

Paste App is a lightweight productivity tool designed for storing and managing text snippets. It provides a seamless experience for creating, editing, viewing, searching, copying, and deleting pastes while maintaining data locally within the browser.

This project was built to strengthen my understanding of modern React development, component-based architecture, state management, routing, and frontend best practices.

---

## ✨ Features

- 📝 Create new text pastes
- ✏️ Edit existing pastes
- 👀 View saved pastes
- 🔍 Search pastes instantly
- 📋 Copy paste content to clipboard
- 🗑️ Delete unwanted pastes
- 💾 Local Storage persistence
- 📱 Fully Responsive UI
- ⚡ Fast performance using Vite

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/Anusudha18/Paste-App.git
```

Navigate to the project directory:

```bash
cd Paste-App
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
